# 🍮 Gaziantepli Künefeci Faruk Usta – Kurumsal Web Sitesi

Bu proje, Gaziantepli Künefeci Faruk Usta için geliştirilmiş modern ve mobil uyumlu bir kurumsal web sitesidir.  
Amaç; markanın dijital görünürlüğünü artırmak, kullanıcı dostu bir arayüz sunmak ve SEO uyumlu bir yapı oluşturmaktır.

🔗 **Canlı Site:**  
http://www.gazianteplikunefecifarukusta.com/

---

## 🚀 Proje Özellikleri

- Responsive (Mobil Uyumlu) Tasarım
- SEO Uyumlu HTML Yapısı
- Hızlı Yükleme Optimizasyonu
- Modern ve Kullanıcı Dostu Arayüz
- Domain & Hosting Kurulumu
- Sitemap ve Arama Motoru Optimizasyonu

---

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Bootstrap (kullandıysan silme, kullanmadıysan kaldır)
- Google Fonts
- Font Awesome
